FAR Flashcards PWA

This folder is a complete installable web app.

To use on iPhone:
1. Host the folder on any HTTPS static host (GitHub Pages, Netlify, Cloudflare Pages, etc.).
2. Open the hosted URL in Safari.
3. Tap Share.
4. Tap Add to Home Screen.
5. Open FAR Cards from the Home Screen.

The app stores flashcards and ratings locally on that iPhone/browser.
